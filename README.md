# 老人桌面（ElderAndroidLauncher）

一个给老人用的 Android 桌面（Launcher）：超大时钟、大方格、一键拨号、语音报号、通话自动免提，
并配一个 Magisk 模块把它锁死成系统默认桌面 —— 老人退不出去、误装不了 App、音量永远最大。

目标机型：红米 K30i / Android版本最低Android11及以上（minSdk 30，targetSdk 37），miui版本应至少12.5及以上，请给老人桌面授权root权限以及设置中授权所有权限（如定位等）
当前软件均为免费给到大家使用，禁止售卖

功能一览

桌面
- 方格桌面，默认 5 行 × 3 列，可在设置里切 **2 列 / 3 列**（列数越少格子越大），最多 30 行 90 格，可上下滑动
- 顶部 **80sp 超大时钟** + 日期星期；右上角竖排显示电量（充电时闪电在数字左边）和媒体音量
- 桌面壁纸：8 种纯色预设，或从相册选照片；格子透明 + 粗白边，文字白色带黑描边，任何背景都看得清

四个固定格（不可编辑、不可删除）
| 格子 | 功能 |
| --- | --- |
| 第 1 格 | 手电筒（Camera2 开关闪光灯，亮起时格子变琥珀色） |
| 第 2 格 | 屏幕亮度循环切档 24% → 50% → 75% → 100% |
| 第 3 格 | 拨号盘（大按键 + 语音报号） |
| 第 4 格 | 零钱包（直达微信收付款，可在设置里关闭） |

拨号与通话
- 4×3 大按键拨号盘，按数字键用**离线 TTS 语音报号**（不联网）
- 号码校验：11 位手机号或 3~6 位短号（10086 / 110 …），位数不对会语音提示且不拨出
- **通话自动免提**：接通后自动开外放，挂断恢复（Root 指令兜底）

提醒
- **整点报时**（默认关闭）：可选 关闭 / 每 1 小时 / 每 30 分钟，语音播报「现在是下午3点整」
- **低电量弹窗**：≤15% 弹出，只能点【好的】关闭

管控
- **自动回弹**：离开桌面进入非白名单 App，无障碍服务自动拉回桌面
- **白名单 / 黑名单**：白名单允许使用；黑名单一打开就强制回桌面并清理后台
- **强制阻止安装模式**（默认开启）：拦安装器与应用市场界面，冻结各应用市场，撤销第三方「请求安装」权限，禁止未知来源；只留电脑 `adb install`
- **每小时强制清理内存**：对所有第三方 App 执行「强行停止」，只保留老人桌面、微信、电话相关和当前正在用的前台应用
- **音量锁定**：媒体 / 铃声 / 通知 / 闹钟等拉满并锁定，被改小后 1 秒内自动拉回

系统级防退出（Magisk 模块提供）
- 开机自动设为默认桌面，被清掉会自动补回
- Root 保活 `oom_score_adj = -1000`，桌面被杀 5 秒内自动拉起
- 自动授予运行时危险权限（通话状态 / 相机 / 存储）
- 自动开启无障碍服务，被系统禁用时自动恢复
- 返回键拦截（桌面按返回只提示「已锁定在老人桌面」）
- 跑到别的桌面（MIUI 桌面等 15 个包名）会被拉回
- APK 自动更新：丢新 APK 到 `/sdcard/ElderLauncher.apk` 即自动安装升级

## 环境要求

- 已 **Root** 的 Android 手机，装有 **Magisk**（模块 `minMagisk=20400`）
- Android 8.0 以上（本项目按 Android 11 / API 30 适配与测试）
- 电脑侧（仅自己编译时需要）：JDK 21、Android SDK

---

## 安装

1. 下载发布包 `ElderAndroidLauncher.zip`（Magisk 模块，内含最新 APK）
2. 传到手机：
3. 手机打开 **Magisk App → 模块 → 从本地安装** → 选择该 zip
4. **重启**

重启后模块会自动完成（无需手动干预）：
- 安装 APK 到 `/system/priv-app`（系统级预装，无法被卸载）
- 设为默认桌面并拉起
- 授予 `READ_PHONE_STATE`（通话免提）、`CAMERA`（手电筒）、存储（壁纸）权限
- 写入并开启无障碍守护服务
- 开启 Root 保活

5. 若开机弹出「选择主屏幕应用」→ 选 **老人桌面** → 点 **始终**

## 给老人怎么用

| 想做什么 | 操作 |
| --- | --- |
| 看时间 / 电量 / 音量 | 看桌面顶部即可 |
| 开手电筒 | 点第 1 格，再点一次关 |
| 调亮度 | 点第 2 格，每点一次换一档 |
| 打电话 | 点第 3 格 → 按大数字键（每按一个会念出来）→ 点拨号键，接通后自动免提 |
| 微信付款 | 点第 4 格「零钱包」 |
| 打开常用 App / 打给家人 | 点对应格子 |
| 不小心按返回键 | 退不出去，只会提示「已锁定在老人桌面」 |
| 按 Home 键 | 回到老人桌面（它就是默认桌面） |

音量由系统自动拉满并锁住，不用担心老人听不见铃声。

## 给家属怎么配置

### 进入设置
点桌面**最后一格「设置」** → 输入管理密码（**默认 `123456`，建议第一时间修改**）→ 进入配置页。
### 编辑某个格子
1. 回到桌面，**按住**要编辑的格子 **4 秒**（底部蓝色进度条走满，手机震一下）
2. 输入密码 → 弹出编辑框
3. 选择类型：
   - **打开应用** → 从应用列表里挑
   - **拨号** → 填电话号码
   - **微信** → 填好友微信 ID（留空则打开微信主界面）
4. 可选：点「从相册选照片」把格子图标换成照片（例如家人头像，老人更好认）
5. 点「保存」

> 第 1~4 格是固定格，长按只会提示「不可编辑」。

### 配置页各项说明
| 项目 | 说明 |
| --- | --- |
| 桌面网格列数 | 切换 2 列 / 3 列 |
| 音量锁定 | 拉满并锁定所有音量 |
| 自动回弹 | 离开桌面就拉回来 |
| 强制阻止安装模式 | 拦安装器与应用市场（默认开启） |
| 零钱包按钮 | 第 4 格开关，关闭后后面的格子自动前移 |
| 整点报时 | 关闭 → 每 1 小时 → 每 30 分钟 循环切换 |
| 桌面背景 | 纯色 / 相册照片 / 恢复默认 |
| 开启无障碍服务 | 跳系统设置页手动打开（自动回弹依赖它） |
| 申请悬浮窗权限 | 置顶弹窗用 |
| 申请修改系统设置 | 亮度调节需要 |
| Root 保活 | 立即执行一次保活 |
| 新增格子 / 新增一行 | 扩展格子 |
| 白名单 / 黑名单应用 | 管控老人能用哪些 App |
| 修改管理密码 | 改掉默认密码 |
| 临时退出桌面 60 秒 | 临时解除锁定，60 秒后自动恢复 |
| 返回桌面 | 退出配置页 |

首次配置建议依次点一次：**开启无障碍服务 → 申请悬浮窗权限 → 申请修改系统设置 → Root 保活**。

## Magisk 模块做了什么
模块是一个 `late_start service` 脚本（`magisk/ElderLauncher/service.sh`），开机以 root 身份执行并常驻巡检：
| 周期 | 动作 |
| --- | --- |
| 开机 | 安装 / 升级 APK、设默认桌面、授予权限、开无障碍、Root 保活、应用安装策略 |
| 5 秒 | 查前台应用：命中黑名单 → 强杀并回桌面；命中内置「别的桌面」名单 → 拉回 |
| 30 秒 | 补写 `oom_score_adj = -1000` |
| 60 秒 | 检查 APK 更新（热更新）、补运行时权限、检查无障碍服务存活、校验默认桌面 |
| 1 小时 | 强制清理全部第三方 App（保留老人桌面 / 微信 / 电话 / 当前前台应用） |



## 常见问题

**默认桌面掉了，回到原厂桌面 / 弹选择器**
```bash
adb shell su -c "cmd package set-home-activity com.example.androidlauncher/.ui.MainActivity"
adb shell su -c "cmd role add-role-holder android.app.role.HOME com.example.androidlauncher 0"
```
模块每 60 秒也会自动校验并补回。
**按最近任务键能退出桌面**
基本等于无障碍守护没在运行（APK 升级后系统会禁用该包的服务）。刷最新模块后，连续 3 分钟检测不到服务会自动重启桌面恢复：
```bash
adb shell su -c "settings get secure enabled_accessibility_services"
adb shell su -c "dumpsys accessibility | grep -i androidlauncher"
```
**拨号按数字不报号**
多为语音引擎被清理，模块已内置保护。可自查当前引擎：
```bash
adb shell su -c "settings get secure tts_default_synth"
adb shell su -c "grep -E 'clean|TTS' /data/local/tmp/elder_launcher.log | tail -10"
```
**想临时装个 App**
配置页 →「临时退出桌面 60 秒」，或临时关闭「强制阻止安装模式」（该模式下只保留 `adb install`）。


**能加定位么？**
可以直接在对应品牌手机上登录账号，即可查看定位。

**能不能跳广告？**
当前所有版本均做了弹窗强制关闭功能（3 秒），去广告的功能因为涉及到无障碍权限以及相关 App 厂商的限制（简称不想收律师函）没做，不过当前版本会在手机端黑屏 10 分钟后强制关闭后台软件

**能不能一键拨打某信视频和语音**
当前所有版本因为涉及到无障碍权限，这个权限会因为品牌手机的底层设置不同，可能存在一些过 24 小时 自动关闭权限的问题，所以无障碍权限的功能在考虑过后移除。

**如何使用**
以 MIUI 系统的 K30 系列 为例，手机必须在 Android11 及以上版本，MIUI 系统应在 12.5 及以上版本， 先装桌面 App，再去刷入 zip 模块，顺序不能搞反，否则模块会连自己的桌面 App 一起禁止安装！部分面具会安装失败，请更换再安装

由于没有精简系统 App，请如果自动接听电话失败，在 MIUI 直接搜接听电话，可以自动接听，模块会自动打开免提（5 秒后），如果弹出小爱同学等，请自行设置一个应用锁锁住（兜底方案）
